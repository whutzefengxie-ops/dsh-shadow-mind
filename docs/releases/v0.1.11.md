# v0.1.11 — DSH 0.2.2-rc.5 compatibility

Targets DSH **0.2.2-rc.5**, source commit `9c2670d3bce5275e0d1610272958121af87787bb`, with Node.js **>=24.9.0**.

Shadow Mind v0.1.10 declares rc.3 as its required DSH engine, so rc.5 rejects it. v0.1.11 updates the exact engine and peer versions and builds against the rc.5 source. Use v0.1.10 for DSH 0.2.2-rc.3.

## Install

Pin the matching DSH prerelease explicitly:

```sh
npx @deepseek-ai/dsh@0.2.2-rc.5 plugin --profile web add github:whutzefengxie-ops/dsh-shadow-mind#v0.1.11
```

Alternatively, download `whutzefengxie-ops-dsh-shadow-mind-0.1.11.tgz` and `SHA256SUMS.txt`, verify the SHA-256, and pass the absolute tarball path to `plugin --profile web add`. Restart the selected profile. No version exemption is required.

For Desktop, confirm that the bundled CLI reports **0.2.2-rc.5**, quit the app, and use its actual home:

```powershell
$env:DSH_HOME = '<actual Desktop DSH_HOME>'
& 'G:\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd' --version
& 'G:\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop add '<absolute tarball path>'
```

Reopen the app, check Plugins and Settings → Built-in Plugins → Shadow Mind, and verify a real file-reading turn produces a review. Web and Desktop profiles are managed independently.

## Rollback

Preserve the previous package, profile manifest and patch, and Shadow definitions before upgrading. Stop the selected profile or quit Desktop, reinstall the previous plugin together with its matching DSH version, and restart. Preserve Session history and credentials.
