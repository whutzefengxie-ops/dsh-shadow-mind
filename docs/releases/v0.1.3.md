# v0.1.3 — Shadow client compatibility with DSH 0.1.6

Fixes `Failed to load plugins @whutzefengxie-ops/dsh-shadow-mind` after upgrading to DeepSeek Harness `0.1.6-alpha.2`. The Host and Client RPC descriptors now supply the codec factories required by the current Typert registry. Shadow settings resolve the Session retained by the main view, and report cards open child Sessions through `uiWorkspace.openSession`.

> **中文摘要**：v0.1.3 修复升级 DSH `0.1.6-alpha.2` 后 Shadow 插件加载失败的问题，补齐 RPC 校验器工厂，并适配设置页当前会话选择和报告卡片子会话导航。安装后需重启对应的 DSH profile。

## Compatibility

- Verified baseline: DSH `0.1.6-alpha.2`, official Harness commit `ddefc45fbc7f8e46dd73185e68295696d1297887`.
- Earlier DSH APIs are unsupported. Use Shadow v0.1.2 for the DSH `0.1.5-rc.2` baseline.
- The maintained release series is v0.1.x; the archived v0.2.x releases target an older DSH API.

## Verification

- [PR #36](https://github.com/whutzefengxie-ops/dsh-shadow-mind/pull/36) passed CI: Host and Client typechecks, 31 test files / 217 tests, Typert consistency, build and bundle smoke checks, committed-artifact reproducibility, and package dry run.
- A live Web profile loaded the fixed plugin; Shadow catalog and model-catalog HTTP requests succeeded.
- The PR includes a browser demonstration of Shadow settings and a real DeepSeek-V41-Flash response. Its isolated host retained local session-migration edits. A separate file-reading attempt hit the host error `Cannot read properties of undefined (reading 'prepare')`; the successful model round used no tools. The demonstration does not verify a complete Shadow child-agent run.

## Install

```sh
dsh plugin --profile web add github:whutzefengxie-ops/dsh-shadow-mind#v0.1.3
```

Restart the selected DSH profile after installation. GitHub installation uses the committed `lib/` artifacts and requires no local plugin build. This release is distributed through GitHub; it does not publish a new npm version.
