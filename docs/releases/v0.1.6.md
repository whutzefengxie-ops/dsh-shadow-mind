# v0.1.6 - Complete npm DSH 0.2.0-rc.2 compatibility

Includes the v0.1.5 ConfigForms and profile-backed settings fixes that resolve `waiting for service: settingsScope`.

Real-model acceptance exposed a second issue: after tool-free think-first planning, DSH declares every investigation tool with `defer_loading=true`. DeepSeek rejects this with HTTP 400 (`at least one tool must have defer_loading=false`). Shadow now starts a distinct request series when investigation begins, preserving tool-free planning and declaring the restored tools immediately through the supported Session contract.

The debug CLI also discovers versioned Session logs such as `session.v4.jsonl.zstd`.

## Compatibility and Installation

Supported DSH: **0.2.0-rc.2**, npm release source `639ed015397290b3745d163aafe02ffee4aa3f84`.

```sh
npx @deepseek-ai/dsh@0.2.0-rc.2 plugin --profile web add github:whutzefengxie-ops/dsh-shadow-mind#v0.1.6
npx @deepseek-ai/dsh@0.2.0-rc.2 web
```

Restart the Web process after upgrading. Existing Shadow definitions remain in `$DSH_HOME/shadow-minds`.
