# v0.1.7 compatibility update (unreleased)

Targets DSH **0.2.1-rc.2**, upstream source commit `687f282e8625c6b8d11ff58211a90524be2e4317`. This document does not imply a published Git tag or GitHub Release.

The removed `subagents.start()` API is replaced by `startActivation({ delivery: 'caller' })`. DSH owns directory selection, inherited policy, capacity, child publication and disposal. Shadow installs its per-review restrictions before initial input, preserves its structured-result validation and routes accepted reports through its existing batcher. Cancellation remains connected after publication. Completed review evidence remains available for diagnostics after automatic teardown. An unconditioned start or cold resume is rejected; start/retry reviews from the parent session.

## Desktop installation

1. Run `pnpm run check` and `npm pack --pack-destination <output>`.
2. Record Desktop's actual `DSH_HOME` and current `profiles/desktop/package.json` and lockfile. Fully quit the application.
3. Run the installed Desktop command, with that home selected:

```powershell
$env:DSH_HOME = '<actual Desktop DSH_HOME>'
& 'G:\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop add '<absolute tarball path>'
```

4. Reopen Desktop. Confirm Shadow Mind appears in Plugins, its settings load, and a real file-reading root turn produces a completed review card. Check the child tool result and terminal event; a visible card alone does not prove model completion.
5. Restart once more and verify settings and accepted-report history persist.

Rollback a first installation by fully quitting Desktop and using the same command with `plugin --profile desktop remove @whutzefengxie-ops/dsh-shadow-mind`, then reopening. For an upgrade, reinstall the previous reviewed package with the matching DSH version. Preserve all Session history and definitions.

## Verification boundaries

Unit/AgentLoop, built Loader, Client activation and profile-settings checks use the exact source baseline. Desktop acceptance additionally requires the installed application and its own profile. No old DSH versions are claimed compatible.
