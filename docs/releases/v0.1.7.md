# v0.1.7 — DSH 0.2.1-rc.2 Desktop compatibility and request recovery

Targets DSH **0.2.1-rc.2**, upstream source commit `687f282e8625c6b8d11ff58211a90524be2e4317`. Distributed through the immutable `v0.1.7` GitHub tag and the package tarball attached to its Release.

The removed `subagents.start()` API is replaced by `startActivation({ delivery: 'caller' })`. DSH owns directory selection, inherited policy, capacity, child publication and disposal. Shadow installs its per-review restrictions before initial input, preserves its structured-result validation and routes accepted reports through its existing batcher. Cancellation remains connected after publication. Completed review evidence remains available for diagnostics after automatic teardown. An unconditioned start or cold resume is rejected; start/retry reviews from the parent session.

## Malformed tool response recovery

Shadow children now recover once from a confirmed malformed DeepSeek tool-JSON attempt through DSH request recovery. Earlier successful steps are preserved; failed response content is never repaired or added to model history. The extra retry is bounded to one per review, respects cancellation and existing provider recovery, and records metadata beside the retained failed attempt. A terminal provider failure now includes its actual message and code.

This is recovery from a provider-side malformed response, not a change to the Messages protocol parser. A DSML fragment inside streamed JSON remains invalid. Repeated malformed responses still fail after the one automatic retry; generation and API-service causes cannot be separated without the provider's raw wire evidence.

## Desktop installation

1. Download `whutzefengxie-ops-dsh-shadow-mind-0.1.7.tgz` from the [v0.1.7 Release](https://github.com/whutzefengxie-ops/dsh-shadow-mind/releases/tag/v0.1.7). For a source build, run `pnpm run check` and `npm pack --pack-destination <output>`.
2. Record Desktop's actual `DSH_HOME` and current `profiles/desktop/package.json` and lockfile. Fully quit the application.
3. Run the installed Desktop command, with that home selected:

```powershell
$env:DSH_HOME = '<actual Desktop DSH_HOME>'
& 'G:\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop add '<absolute tarball path>'
```

4. Reopen Desktop. Confirm Shadow Mind appears in Plugins, its settings load, and a real file-reading root turn produces a completed review card. Check the child tool result and terminal event; a visible card alone does not prove model completion.
5. Restart once more and verify settings and accepted-report history persist.

Rollback a first installation by fully quitting Desktop and using the same command with `plugin --profile desktop remove @whutzefengxie-ops/dsh-shadow-mind`, then reopening. For an upgrade, reinstall the previous reviewed package with the matching DSH version. Preserve all Session history and definitions.

## Validation

- Full local check: 35 test files, 237 tests, Host/Client typechecks, Typert consistency, build and bundle syntax checks.
- The captured malformed tool argument fixture was replayed through the pinned DSH SSE decoder and Messages translator, including byte-level UTF-8 splitting; invalid JSON is retained exactly and rejected, while a valid Chinese JSON control succeeds.
- Installed Desktop 0.2.1-rc.2: a controlled replay of the failed attempt recovered automatically in the same child, followed by a real DeepSeek request, successful structured output, and report delivery to the parent.
- After removing the temporary replay component and restarting Desktop, a separate real DeepSeek review completed without any failed attempt or retry. The previous accepted card survived restart.
- Default review settings were restored after validation. Recovery handles a malformed provider response; it does not eliminate malformed model/API output.

## Verification boundaries

Unit/AgentLoop, built Loader, Client activation and profile-settings checks use the exact source baseline. Desktop acceptance additionally requires the installed application and its own profile. No old DSH versions are claimed compatible.
