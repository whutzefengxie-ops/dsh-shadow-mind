# v0.1.8 — DSH 0.2.2-rc.1 compatibility

Targets DSH **0.2.2-rc.1**, source commit `66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db`, with Node.js **>=24.9.0**. Use the immutable GitHub tag or the attached package tarball.

Shadow reviews now own a native tool executor. The first think-first request has no tools, investigation restores immediate native tools, and the review allowlist filters both declarations and actual dispatch, including child-local tools. Parent sessions may use native or PTC execution. Child model selection uses `agent.model.select()` before step preparation fixes the route.

## Install

Download `whutzefengxie-ops-dsh-shadow-mind-0.1.8.tgz`, fully quit Desktop, and use its bundled CLI with the actual Desktop home:

```powershell
$env:DSH_HOME = '<actual Desktop DSH_HOME>'
& 'G:\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop add '<absolute tarball path>'
```

Reopen Desktop, open Plugins → Shadow Mind, and verify a tool-using root turn produces a completed review. For Web:

```sh
npx @deepseek-ai/dsh@0.2.2-rc.1 plugin --profile web add github:whutzefengxie-ops/dsh-shadow-mind#v0.1.8
```

Preserve the previous package, profile manifests/patches, and Shadow definition before upgrading. For rollback, fully quit Desktop, reinstall the previous plugin package with its matching DSH version, and reopen. Do not remove Session history or credentials.
