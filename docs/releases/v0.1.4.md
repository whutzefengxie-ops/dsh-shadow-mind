# v0.1.4 — Shadow compatibility release for DSH 0.1.6

This release republishes the Shadow client compatibility fix from [PR #36](https://github.com/whutzefengxie-ops/dsh-shadow-mind/pull/36) under a new tag. Runtime source and committed `lib/` artifacts are identical to v0.1.3; package metadata and installation instructions use v0.1.4.

> **中文摘要**：v0.1.4 使用新 tag 重新发布 DSH `0.1.6-alpha.2` 兼容性修复，解决 Shadow 插件加载失败，并适配设置页当前会话选择和报告卡片子会话导航。运行时代码与 v0.1.3 相同。

## Included fixes

- Host and Client RPC descriptors provide the `create()` codec factories required by the current Typert registry, fixing `Failed to load plugins @whutzefengxie-ops/dsh-shadow-mind`.
- Settings resolve the Session retained by the main view; report cards open child Sessions through `uiWorkspace.openSession`.

## Compatibility and validation

- Verified baseline: DSH `0.1.6-alpha.2`, official Harness commit `ddefc45fbc7f8e46dd73185e68295696d1297887`. Earlier DSH APIs are unsupported; use Shadow v0.1.2 for the DSH `0.1.5-rc.2` baseline.
- The unchanged implementation passed Host and Client typechecks, 31 test files / 217 tests, Typert consistency, build and bundle smoke checks, committed-artifact reproducibility, and package validation in [CI](https://github.com/whutzefengxie-ops/dsh-shadow-mind/actions/runs/35500185208).
- The v0.1.3 browser demonstration verified settings activation and a real model response, but did not establish a complete Shadow child-agent run. See [the verification limits](https://github.com/whutzefengxie-ops/dsh-shadow-mind/releases/tag/v0.1.3).

## Install

```sh
dsh plugin --profile web add github:whutzefengxie-ops/dsh-shadow-mind#v0.1.4
```

Restart the selected DSH profile after installation. GitHub installation uses committed `lib/` artifacts and requires no local plugin build. This GitHub release does not publish a new npm version. The maintained release series is v0.1.x; archived v0.2.x releases target an older DSH API.
